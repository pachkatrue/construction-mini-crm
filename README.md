# BuildFlow CRM

Мини-CRM для управления строительными объектами и задачами.

## Текущий статус

В репозитории находится первый этап разработки: базовый React + TypeScript + Vite интерфейс с демонстрационными данными. SQL-схема, RLS-политики и инструкция по настройке Supabase уже добавлены. Подключение авторизации и загрузки данных из Supabase выполняется следующими этапами.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Технологии

- React 18 + TypeScript
- Vite
- Supabase JS client (подключение настраивается через переменные окружения)

## Важно

Пока основной экран использует демонстрационные данные. SQL-миграция и базовый слой Supabase Auth добавлены, но полный переход интерфейса на реальные данные ещё не завершён.
