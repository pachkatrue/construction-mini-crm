# BuildFlow CRM

Мини-CRM для управления строительными объектами и задачами.

## Текущий статус

В репозитории находится первый этап разработки: базовый React + TypeScript + Vite интерфейс с демонстрационными данными. Подключение Supabase, SQL-схема, RLS-политики и проверка жизненного цикла задач будут добавлены отдельными коммитами.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Технологии

- React 18 + TypeScript
- Vite
- CSS без дополнительной UI-библиотеки на первом этапе

## Важно

Пока приложение работает на демонстрационных данных в браузере. Это не production-версия: авторизация, разграничение доступа и сохранение данных через Supabase ещё не подключены.
